⚠️ La tabla no tiene columna updated_at — no se puede ordenar por fecha de cambio.
Para activar el historial completo, ejecutá en Supabase SQL Editor:

ALTER TABLE votos ADD COLUMN updated_at timestamptz DEFAULT now();
CREATE OR REPLACE FUNCTION set_updated_at() RETURNS trigger AS $$ BEGIN NEW.updated_at = now(); RETURN NEW; END; $$ LANGUAGE plpgsql;
CREATE TRIGGER votos_updated_at BEFORE UPDATE ON votos FOR EACH ROW EXECUTE FUNCTION set_updated_at();
